# Lince Tech Academy

Este repositório contém a resolução de exercícios propostos na disciplina de Programação Orientada a Objetos (POO).

## Linguagem utilizada
- Java

## Descrição
Os exercícios foram implementados com foco em lógica de programação e conceitos básicos de Programação Orientada a Objetos, utilizando a linguagem Java.

## Conteúdo
Cada atividade está organizada separadamente, contendo sua respectiva solução.
